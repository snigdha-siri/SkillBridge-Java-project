# SkillBridge – A Skill-to-Opportunity Matching Platform

## 1. Project Overview

SkillBridge is a Java-based console application designed to connect candidates' skills with the requirements of different opportunities.

The main idea of this project is to help candidates understand how well their existing skills match an opportunity and identify the skills they need to improve.

The application compares candidate skills with required skills, calculates a matching percentage, displays matched and missing skills, and provides learning recommendations for missing skills.

## 2. Problem Statement

Candidates often find it difficult to identify opportunities that match their current skill sets. They may also be unaware of the specific skills they need to develop to become suitable for an opportunity.

SkillBridge aims to address this problem through a simple skill-comparison and recommendation system.

## 3. Objectives

- To maintain candidate skill information.
- To maintain opportunity details and required skills.
- To compare candidate skills with opportunity requirements.
- To calculate skill-matching percentages.
- To identify matched and missing skills.
- To provide learning recommendations for missing skills.
- To help candidates understand areas where they can improve.

## 4. Key Features

1. **Add Candidate:** Enter a candidate's name and skills.
2. **Add Opportunity:** Enter an opportunity title, company name and required skills.
3. **Find Matches:** Compare candidate skills with opportunity requirements.
4. **Matching Percentage:** Calculate how closely a candidate's skills match an opportunity.
5. **Matched and Missing Skills:** Display skills the candidate already has and skills that need improvement.
6. **Learning Recommendations:** Suggest learning areas based on missing skills.
7. **View Candidates:** Display all registered candidates.
8. **View Opportunities:** Display all available opportunities entered into the application.

## 5. How It Works

1. The user enters candidate details and skills.
2. Opportunity details and required skills are added.
3. The application compares both skill sets.
4. It calculates the matching percentage.
5. It displays matched and missing skills.
6. It provides learning recommendations for missing skills.
7. Opportunities are arranged according to their matching percentages.

## 6. Technologies Used

## 7. Matching Logic

The application uses skill-set comparison to identify common and missing skills.

**Matching Percentage Formula:**

Matching Percentage = (Number of Matched Skills / Total Required Skills) × 100

## 8. Applications

- Candidate skill assessment

## 9. Future Enhancements

- Database integration for permanent data storage.
- User-friendly graphical interface.
- Candidate registration and login.

## 10. Project Limitations

This version is a console-based Java application. Candidate and opportunity information is stored in memory during execution and is not permanently saved.

The opportunities are entered into the application and are not fetched from live job portals.

## 11. Conclusion

SkillBridge demonstrates how Java programming concepts can be used to develop a practical skill-to-opportunity matching application. It helps candidates understand their skill compatibility, identify missing skills and explore areas for further learning.

This project provided practical experience in Java programming, object-oriented concepts, collections and problem-solving.
